# Repository layout

This page lists every tracked file in the repository and what it is for.
Files matching `LAYOUT_EXEMPT` in `tools/build_readme.py` are left out.
`LAYOUT_EXEMPT` is one verbose regular expression (`re.X`), searched against each
repo-relative path. To exempt a file, add an alternative such as
`| ^tools/scratch/` on its own line, with a `#` comment saying why.

Everything between the markers below is generated by `tools/build_readme.py`,
from `git ls-files` and the `LAYOUT` table in that script. Do not edit it by
hand. To change a row, edit `LAYOUT` in `tools/build_readme.py` and run
`python3 tools/build_readme.py`.

For a new file, `python3 tools/build_readme.py --add-missing` adds a row to
`LAYOUT`, taken from the file's own docstring or header comment. Then run
`python3 tools/build_readme.py` to rebuild this page.

When you delete a file, delete its row from `LAYOUT` in `tools/build_readme.py`,
then run `python3 tools/build_readme.py`.

CI runs `python3 tools/build_readme.py --check-layout`. It fails if a tracked
file has no row, if a row names a file that no longer exists, or if this page
does not match the table.
