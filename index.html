Sync progress

Your progress is saved in this browser only. To carry on on another device, make a code here, then scan or type it on that device. If the other device already has a code, enter that code above instead of making a new one.

On your other device, point the camera at this square. It opens this site with your code already filled in. There is no app to install.

Or type the code on the other device: open Sync there, enter it and press “Use this code”.

Anyone with this code can see and change your progress. That is all it unlocks: it holds crossword letters and nothing personal. Syncing combines the letters from every device, so filling in squares on one never erases squares filled on another.

    Never solved a cryptic?

    Every clue has two parts: a plain definition of the answer at one end, and wordplay that builds the same answer another way.

    Nobody spots that on day one. Every clue here comes with a row of hints, and each one gives away a little more than the one before. Start with the first, and stop as soon as you can see the answer.
